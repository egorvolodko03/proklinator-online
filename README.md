# ⚡ Проклинатор онлайн (Online Cursinator)

> **«Одно действие — и вы счастливы. Направьте космическую бюрократию на обидчика.»**  
> *Вирусное интерактивное веб-приложение в эстетике «Темной Канцелярии Космической Кармы».*

---

## 🔮 О проекте

«Проклинатор онлайн» позволяет направить безжалостную космическую бюрократию и абсурдные микро-кары на обидчиков (шумных соседей, токсичных коллег, бывших или автохамов) и сгенерировать официальную **Грамоту Проклятия** с сургучной печатью для отправки жертве.

### ✨ Возможности:
- 🔥 **Алтарь (Landing)** с пульсирующим счетчиком совершенных приговоров и живой лентой хроники возмездия.
- 📜 **Пошаговый ритуал (4 шага)**: выбор жертвы, протоколирование греха с рандомайзером, 3 уровня кармической строгости (🟢 *Легкий дискомфорт*, 🟡 *Офисный ад*, 🔴 *Кармический крах*) и ролл из 30+ остроумных кары.
- 📡 **Астральное согласование**: анимация вращающейся рунической печати, звуковые эффекты и мистический залп конфетти.
- 📜 **Официальная Грамота Проклятия**:
  - Уникальный номер дела (напр. `#КРМ-84920-Б`), штрихкод и подпись секретаря.
  - Скачивание в PNG высоком разрешении.
  - Персонализированная ссылка для жертвы (с открытием прямого вердикта).
  - Шеринг в Telegram.
- 🔊 **Web Audio API**: встроенный генератор мистических звуковых эффектов (работает офлайн без внешних аудиофайлов).
- 🛡️ **Откуп от кармы / Индульгенция**: шуточный механизм пожертвований темным клеркам.

---

## 🛠 Стек технологий

- **Фреймворк**: Next.js 14 (App Router)
- **UI & Анимации**: React 18, Tailwind CSS, Framer Motion, Lucide React
- **Экспорт & Эффекты**: `html-to-image`, `canvas-confetti`, HTML5 Canvas Particle System
- **Аудио**: Web Audio API Synthesizer

## 🚀 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

---

## 📦 Сборка для продакшена

```bash
npm run build
npm start
```
